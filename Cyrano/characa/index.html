FF14 キャラカメーカー

デザイン

枠の形

パネル(図形)の形がまとめて変わります。細い帯や線には飾りを付けません。

配色

色を細かく変える

要素の色で「配色の色」を選んでいると、ここの色に合わせて変わります。

キャラのスクショ

カード上の画像枠にドラッグ&ドロップでも入れられます。

Lodestoneから文字情報を取得

ID はキャラページの URL 末尾の数字です
例: jp.finalfantasyxiv.com/lodestone/character/12345678/

名前・ワールド・ジョブレベルなどがカードに入ります。

キャラ情報(手入力・修正もできます)

要素を追加

押すと、カードの真ん中に追加されます。

選択中の要素

クリックで選択 / ドラッグで移動 / 辺・角(ピンクの●)をドラッグで大きさを変える(角は Shift で縦横比を保つ) / 画像はホイールでズーム・Alt+ドラッグで位置調整 / 矢印キーで微調整(Shiftで10px) / Deleteで削除 / 表示の拡大縮小は下の＋－・素材の無い所でホイール・Ctrl+ホイール / 表示を動かすのは余白のドラッグ・スペース+ドラッグ

レイヤー

上にあるものほど前面です。押すと選択して、「要素」タブで調整できます。ドラッグで順番を入れ替えられます(行の上で離すと、その行のすぐ下に入ります。スマホは、行を長押ししてから動かします)。

    カード設定

    自分のデザインを保存・読み込み

    レイアウトはこのブラウザに自動保存されます。

    記載されている会社名・製品名・システム名などは、各社の商標、または登録商標です。
