### ユーザーが画像で指定済みのこと
- **スリースターズの塔**：9本は位置固定（北を避けて20°から40°おき＝南に1本）。属性ごとに3本まとまり（東側・南・西側）、どの属性がどこかはランダム

- **フラッドの予兆**：画像では帯が**斜め45°**（北西〜南東／北東〜南西）に見える。**未反映**（下の課題 6）

## 座標・共通仕様

- キャンバス 800×800、中心 (400,400)、フィールド半径 `ARENA_R = 350`。上が北
- 角度は `polar(deg, r)`：**北が0°で時計回り**（東90°・南180°・西270°）
- フィールドマーカー：**P3（アルテマブラスター）と完全に同じ**。途中で変えられないので全ギミック共通で固定
  - 並び（北から時計回り）: A(北) → 2 → B(東) → 3 → C(南) → 4 → D(西) → 1
  - 半径 `MARK_R = 206`（P3と同じ比率：フィールド半径の約0.59）
  - 色：A/1 赤、B/2 黄、C/3 青、D/4 紫（P3の `GROUP_COLORS` と同じ値）
  - ユーザー指定：**A〜D・1〜4を全部使う**
- 散開位置（オーケストラ・終末の渦）：1人1マーカー `SPREAD_MARK = { MT:A, D2:2, ST:B, D4:3, H2:C, D3:4, H1:D, D1:1 }`（仮）
- 移動速度：自分 105px/秒（Shiftで×1.45）、NPC 150px/秒
- 操作：WASD／矢印／クリック地点へ移動／ジョイスティック（幅960px以下で表示。**指でもマウスでも動く**）

## コードの構成（`SukisugiteZetsuP5.js`）

### セグメント（ギミック1つ分）
各ギミックは `segXxx()` が返すオブジェクト。エンジンが順番に再生する。

| プロパティ | 内容 |
|---|---|
| `name` / `desc` | 名前・解説（右の MECHANIC カードに表示） |
| `duration` | 長さ（秒） |
| `timeline` | `[[秒, 表示名], ...]`（右の TIMELINE と上の NEXT） |
| `init()` | 開始時の抽選（塔の属性・予兆など） |
| `events()` | `[[秒, 関数], ...]`。判定はここで行い、失敗なら `fail("理由")` |
| `target(p, lt)` | そのロールの正解位置（NPCの移動先＋ガイド表示）。`null` ならその場で待機 |
| `guide(p, lt)` | ガイド文 |
| `tick(lt)` | 毎フレームの判定（エクサ・黒い穴など） |
| `draw(lt)` | 予兆などの描画 |

`lt` はセグメント開始からの秒。

### モード
```js
const MODES = {
  aa: { name: "魔撃（AA）", build: () => [segAA(3)] },
  flood: ..., orchestra: ..., stars: ..., exa: ..., missing: ...
};
```
**全編通しは `build` に複数のセグメントを並べるだけで動く**作り（`start` は自動で積み上がる）。

### 共通ヘルパー
- `setCast(名前, 秒)` 詠唱バー / `banner(文字)` / `fxCircle(...)` 着弾エフェクト
- `addDebuff(p, key, label, color, short)` / `removeDebuff(p, key)`（頭上には `short` を表示）
- `aaEvents(list, first, count)` 魔撃を他セグメントに混ぜるとき用
- `S.hate` ヘイト順（オーケストラでスイッチする）

## 各ギミックの現状（数値は仮）

### 魔撃（AA）`segAA(3)`
- 3.5秒から2.4秒おきに3回。タンク2人はA（半径55・2人必要）、ヒーラーは4（半径75・2人）、DPSは3（半径75・4人）
- 失敗：自分の組に入っていない／頭割りが重なる／人数不足

### フラッド `segFlood()`
- 4×4の縦横グリッド。予兆4本（1本＝2列幅、中央列をちょうど1本含む）。①と②は必ず縦横が違う
- 予兆 0.6/1.2/1.8/2.4秒、着弾 5.5/7.1/8.7/10.3秒、カオティックフラッド頭割り 6.3/7.9/9.5/11.1秒（半径70）
- 正解：中央4マスのうち①②の外で待機 → ①着弾後に①の中へ → ②着弾後に②の中へ（`genFlood()` が解のある配置だけ出す）

### 狂気のオーケストラ `segOrchestra(2)`
- 詠唱5秒（散開）→ 5秒：ヘイト1位にフレア、2位にホーリー、ランダム3名に円範囲（散開判定、半径80）
- 6秒で挑発スイッチ → 12秒：フレア（半径330）とホーリー（半径90）が着弾
- 待機：フレアのタンクは北端 (400,85)、ホーリーのタンクはボス前 (400,330)、他6人は南（ヒラは西寄り・DPSは東寄り）
- 14.6秒から魔撃2回

### スリースターズ `segThreeStars()`
- 塔：リング半径158、塔の半径48。詠唱4秒 → 4秒で塔出現・デバフ付与（氷・炎・雷 2人ずつ、無職2人）
- 光る 5/13/21秒、判定 12/19.5/28秒。毎回1属性だけ2本光り、2本の属性は3回とも違う
- 担当：デバフ持ち＝自分の属性の時計回りで次の属性（2本なら手前）、無職＝2本の奥
- 踏むとその属性のデバフに付け替わる（無職は役割のまま）。踏んだ後は次が光るまでその場
- カタストロフ（1回目・3回目、詠唱 7〜12秒・23〜28秒）：緑＝リングより内側、茶＝外側
- 失敗：塔に入っていない／自分のデバフと同じ属性／塔が2人でない／空の塔がある／カタストロフ

### 混沌の終末 `segExa()`
- 北西からと北東からの各6レーン。北西・北東の交互に計6回（5秒から1.6秒おき）。1回＝2レーン（1レーン空き）
- 予兆は着弾の1.6秒前、通過に1.6秒（前線の幅±34）
- NPCは「まだエクサが通過していない交点を避け、一番近い安全な交点へ」移動（`chooseLanes`）
- 17.4秒以降に散開 → 終末の渦（詠唱14秒〜19.5秒、半径75）

### ミッシング・ゼロ `segMissingZero()`
- 詠唱4.5秒でAに集合。以降7.5秒周期で4回：
  - 紫予兆（数字マーカー1つ）→ 3.2秒後に黒い穴（半径60、触れたら即死・以後ずっと残る）と頭割り（半径70）
  - 3.6秒後にオレンジ予兆（アルファベットマーカー1つ、半径85）→ 6.8秒で着弾
- 正解：黒床のない数字で頭割り → オレンジのないアルファベットへ

## 動作確認のしかた

- プレビュー：`.claude/launch.json` の `cyrano-static`（Node の簡易サーバー、ポート8765）。サーバー本体はセッションの scratchpad にあるので、**別セッションでは作り直す**必要あり（`Cyrano` を静的配信できれば何でもよい）
- `SukisugiteZetsuP5.html?auto=1`：自分も正解位置へ自動移動する
- さらに `?auto=1` のときはコンソールで同期テストができる：
  ```js
  window.__p5test("stars", "D1")  // → "DUTY COMPLETE: ..." または "DUTY FAILED: 理由"
  ```
  修正後は全モード×全ロールを数十〜数百回まわして、全部 COMPLETE になることを確認する（現状すべて通る）
- 注意：ブラウザペインが隠れていると描画が止まり、スクリーンショットで進行が見えないことがある
