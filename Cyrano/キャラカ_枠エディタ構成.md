## 目的
- キャラカの中で、自分で枠(パネルの飾り)を作れるようにする
- 作った枠は「枠の形」の一覧に並び、ほかの枠と同じように選べる
- どんな大きさのパネルにも、伸び縮みして合う

---

## 1. 枠のしくみ(3つの部品)

| 部品 | 描く範囲 | カードでの使われ方 |
|---|---|---|
| **土台の形** | 選ぶだけ(丸い角 / 四角 / 角を切る / レースの波) | パネルの塗りと枠線の輪郭 |
| **角の飾り** | 左上の角だけ、正方形のマスの中に描く | 4つの角にコピー。右上・右下・左下は自動で反転 |
| **辺の模様** | 横長の短いマスの中に1つ分描く | 4つの辺に沿って繰り返し並べる。辺の長さに合わせて数と間隔を自動で調整 |

- 角の飾りと辺の模様は、どちらか片方だけでもよい
- 角の飾りがある所には、辺の模様を並べない(重ならないように)

### 大きさの決め方
- 部品は「パネルの短い辺に対する割合」で大きさを決める(例:角の飾りは短い辺の 15%)
- 大きいパネルでも小さいパネルでも、見た目の比率が同じになる
- 細い帯(短い辺が 60px 未満)には、角の飾り・辺の模様を付けない(今の枠と同じ)

---

## 2. 部品の描き方(エディタ)

アイコンメーカー(`tools/icon-maker.html`)と同じ操作にそろえる。

- 描く:クリックで点を置き、なめらかな線でつなぐ。点ごとに「角」にできる。曲がり具合のハンドル
- 閉じた形は「塗る」にできる
- 置ける図形:丸 / 四角 / ひし形 / ハート / 星(サイズと位置をドラッグで調整)
- 線の太さは線ごとに変えられる
- 下書き画像を敷ける(レース素材の画像などをなぞる用)
- 元に戻す・やり直す

### 画面の構成(案)
- 「デザイン」タブの「枠の形」に **「＋自分の枠を作る」** ボタン
- 押すと、カードの上に **枠エディタの画面** が重なって開く(全画面のパネル)
  - 左:部品の切り替え(角の飾り / 辺の模様 / 土台の形)と描くマス
  - 右(スマホは下):実際のパネルに付けたときのプレビュー(横長・正方形・縦長の3つ)
  - 下:「保存して閉じる」「やめる」
- 自分の枠は、一覧で長押し(PCは右クリック)すると「編集」「複製」「削除」

---

## 3. 色

- 部品の線・塗りの色は「配色の色」から選ぶ(アクセント / 文字 / 枠線の色 など)。配色を変えると一緒に変わる
- 「自由に選ぶ」で固定の色にもできる(今の要素の色欄と同じ)

## 4. データと保存

```js
// project.frames(自分の枠の一覧)
{
  id: "my-lace-1",
  name: "自分のレース",
  base: "round",            // 土台の形
  corner: { size: 0.15, paths: [...] },   // 角の飾り(座標はマスの中で 0〜100)
  edge:   { size: 0.06, gap: 0.2, paths: [...] }, // 辺の模様
}
// paths の中身はアイコンメーカーと同じ形:{ pts: [{x, y, corner, hIn, hOut}], closed, fill, w, color }
```

- `project.frame` に自分の枠の id を入れれば、それが選ばれる
- このブラウザに自動保存(今のカードと同じ)
- 「自分のデザインを保存・読み込み」の書き出しにも含める → ほかのカードやほかの端末でも使える
- 枠だけを書き出す・読み込む(枠を人と交換する用)もできるようにするか? → **要相談**

## シンボルエディタ(2026-10-08 追加)

- **symbol-editor.html**:枠エディタの HTML をもとにした別ページ(`<body data-editor="symbol">`)。JS は **frame-editor.js をそのまま流用**(`SYMBOL_MODE` で切り替え)。部品は「シンボル」1つ(`def.symbol.paths`)。描く・動かす・図形・切り抜き・レイヤー・拡大縮小などは枠エディタと同じ
- データ:`{ id, name, w, h, symbol: { paths } }`。w・h は描くマスの大きさ(長い辺が 100)。「詳細」の下の「マスの形」で縦横比を選ぶ(形を変えても線はそのまま)
- 保存先:このブラウザの `characa:symbols`(frames.js の `loadSymbols` / `saveSymbols` / `findSymbol`)。保存すると `index.html?symbol=id`(新しく作ったときは `&add=1` でカードに置く)
- 描き方:frames.js の `drawSymbol(g, sym, x, y, w, h, color)`。箱に合わせて縦横に伸び縮み。**色はキャラカの要素ごと**(全部の線・図形をその色で塗る)。切り抜きはシンボルの中だけ。別 canvas の処理は `drawIsolated` に共通化(枠の切り抜きも同じ)
- キャラカ:要素の種類 `symbol`(`{ symbol: id, w, h, color }`)。選択中の要素に「このシンボルを編集」「このシンボルを削除」(削除すると、カードに置いた分も消える)。書き出しの JSON に使っているシンボル(`customSymbols`)を入れ、読み込みで足す
